# 🔍 Live Search Filter (React)

A modern React app that performs debounced live search on 1000+ entries with highlighted results.

## 🚀 Features
- Live search with debounce
- useEffect cleanup
- Controlled input
- Highlight matched text
- Modern UI
- used in modern applications

## 🛠 Tech Stack
- React
- JavaScript
- CSS
